# Convert Everything

Private, on-device file conversion in the browser. Files are processed locally with JavaScript and WebAssembly and are never uploaded.

```bash
npm install
npm run dev        # http://localhost:4791
npm run build      # production build in dist/
npm test           # unit tests
npm run test:e2e   # browser tests (Chromium, WebKit/iPhone, Firefox)
```

A full README with the compatibility matrix follows as features land.
